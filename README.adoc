= Kuadrant Demo

== Requirements

- OCP >= 4.20
- oc client >= 4.20
- Ansible with Kubernetes module (https://docs.ansible.com/ansible/latest/collections/kubernetes/core/k8s_module.html#requirements[requirements])

== What is available?

. Developer Hub 1.9
. Red Hat build of Keycloak v26
. Tekton Pipelines 1.21
. ArgoCD GitOps 1.19
. Red Hat Connectivity Link 1.3

===  How to run the playbook

----
ansible-playbook \
-e token=${token} \
-e server=${server} \
-e kuadrant_aws_access_key_id=${kuadrant_aws_access_key_id} \
-e kuadrant_aws_secret_access_key=${kuadrant_aws_secret_access_key} \
-e kuadrant_aws_region=${kuadrant_aws_region} \
-e kuadrant_zone_root_domain=${kuadrant_zone_root_domain} \
-e rhdh_github_pat=${github_pat} \
playbook.yml
----

== Testing the Example Application

The testing application comes with some basic scenarios to test the API Gateway functionality. You can use the following curl commands to test the application.

First, get the URL of the application:
----
APP_ROUTE=https://$(oc get httproute hello-openshift-route -n hello-openshift -o jsonpath='{.spec.hostnames[0]}')
----

=== Authorization and Authentication

. 403 error
----
curl -k -v $APP_ROUTE
----

. 200 success
----
curl -k -v -H 'Authorization: APIKEY iamanadmin' $APP_ROUTE
----

=== Rate Limiting

. 429 error
----
for i in {1..6}; do
  curl -k -H 'Authorization: APIKEY iamanadmin' "$APP_ROUTE"
  echo
done
----
